# Gym Web Front End

React + Vite web front end for the gym platform. Currently a UI prototype of the sign-in screen.

## What it holds
- `gym_web_fe/src/components/AuthPage.tsx` - "Welcome Back" login / sign-up screen
- Vite + TypeScript project setup with ESLint

Login is not yet wired to the API ([Gym_backend](https://github.com/khavyas/Gym_backend)).

## Stack
React, TypeScript, Vite, lucide-react

## Run it
```bash
cd gym_web_fe
npm install
npm run dev
```
